
# Karyar Final Front-End Project

## About the Project

This project is an e-commerce website developed as the final project of the Karyar Front-End course. The main goal of this project is to practice and apply fundamental front-end development skills by creating a multi-page website.

## Pages

- **Home Page:** Displays the product listing and product cards.
- **Product Details Page:** Presents detailed information about a selected product.
- **Registration Page:** Provides a page for user registration.

## Technologies Used

- HTML5
- CSS3

## Features

- Product cards with images and product information
- A dedicated page for product details
- Shared header and footer across pages
- Responsive layout for different screen sizes

## Project Structure

- `index.html` — Home page
- `product.html` — Product details page
- `register.html` — Registration page
- `CSS/` — Stylesheets
- `images/` — Product images and other visual assets

## How to Run

1. Clone or download this repository.
2. Extract the files if you downloaded the ZIP archive.
3. Open `index.html` in your web browser.

## Project Purpose

This project was created for educational purposes to strengthen practical front-end development skills and gain experience in building and organizing a multi-page website.
