# Karyar Final Front-End Project

## About the Project

This project is a multi-page Persian e-commerce website developed as the final project of the Karyar Front-End course. It focuses on practicing HTML5, CSS3, responsive design, and organizing a multi-page website.

## Pages

- **Home Page (`index.html`):** Displays product listings and product cards.
- **Product Details Page (`product.html`):** Presents product images and detailed product information.
- **Registration Page (`register.html`):** Provides a user registration form.

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## Features

- Product cards with images and product information
- Product search, filtering, and sorting interface
- Dedicated product details page
- User registration form
- Shared styles across pages
- Responsive layout for desktop and mobile devices
- Vazirmatn Persian font

## How to Run

1. Clone or download this repository.
2. Open the `store` folder.
3. Open `index.html` in your web browser.

## Project Purpose

This project was created for educational purposes as part of the Karyar Front-End course to strengthen practical front-end development skills using HTML and CSS.
